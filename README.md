# 오늘의 한 끼 | My Recipe Book

HTML, CSS, JavaScript 기초 학습용 레시피 웹사이트입니다.

## 페이지 구성
- `index.html`: 메인 페이지와 추천 메뉴
- `recipes.html`: 레시피 목록 및 카테고리 필터
- `recipe-detail.html`: 비빔밥 상세 레시피와 인분별 재료 계산
- `guide.html`: 요리 초보 가이드
- `style.css`: 모든 페이지에서 공통으로 사용하는 스타일
- `script.js`: 두 가지 JavaScript 기능

## JavaScript 기능
1. 레시피 페이지에서 한식/양식/디저트 카테고리 필터링
2. 상세 페이지에서 인분을 선택하면 재료 양 자동 계산

## 실행 방법
1. ZIP 파일을 압축 해제합니다.
2. 위 파일을 모두 같은 폴더에 둡니다.
3. `index.html`을 Chrome 또는 Edge에서 엽니다.
4. 상단 메뉴를 눌러 다른 페이지로 이동합니다.

별도의 설치나 서버 실행은 필요하지 않습니다. Google Fonts를 불러오지 못하는 환경에서는 기본 글꼴로 표시될 수 있습니다.
